# mosegada-lab

Personal lab of quantitative trading projects by **Guillermo Vallejo Maseda**, Computer Engineering student at Universidad Politécnica de Madrid.

Each project is self-contained, with its own README, requirements and instructions to run it.

## Projects

| Project | What it is | Stack |
|---|---|---|
| [**Delta-Neutral Funding Bot**](quant/delta-neutral-funding-bot) | Async trading bot that captures funding-rate spreads between two perpetual futures exchanges (Hyperliquid and Aster) while staying market-neutral. Atomic two-leg execution with rollback, drawdown kill switch, SQLite state recovery and a full paper-trading simulator. | Python · asyncio · SQLite · REST APIs |
| [**Mean Reversion Strategy**](quant/mean-reversion) | Research project: z-score mean reversion strategy with backtesting, risk metrics (Sharpe, max drawdown) and grid-search optimisation with a custom risk/return objective. | Python · pandas · yfinance · matplotlib |
